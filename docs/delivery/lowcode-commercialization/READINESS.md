## LC-07 商城会员基线准备

本机营销 `dev-tenant` 的真实会员等级预估返回一位匹配会员，其他未配对租户的来源保持关闭。验证对象为本机商城示例租户数据。历史本机验证已覆盖五分钟快照、重放和到期拒绝。

- **身份权威。** 商城会员域区分认证主体和业务会员 ID。当前商城画像输出按会员 ID 命名空间处理，营销的一次性快照保存主体摘要。LC-07 需要签收商城会员、稳定营销主体和可信调用来源之间的映射、冲突、解除与合并语义。Decision 运行端和客服查询适用各自身份权限。
- **全量水位。** 当前商城使用单次 SQL 读取在籍会员，超出 10,000 人即拒绝。后续可恢复基线合同要定义固定水位、完整结束标志、分批续跑和校验方式。由 Commerce 确认权威读取入口和授权范围。
- **增量来源。** 已定位会员登记、冻结注销和成长等级更新的写入路径。会员状态和等级由不同写入口修改。现有营销 Flink 接收含 `segmentIds` 的已分群消息，不能据此证明商城状态及等级修改都能传播。LC-07 签收的基线水位需能衔接 LC-08 的变更、撤销和补读。见[画像接入设计](../commerce-member-audience/DESIGN.md)。

会员线当前已完成来源盘点和本机复核。业务身份映射、带固定水位的完整读取、规模与保留期限仍待 Commerce、Auth 和数据治理责任方核定。
